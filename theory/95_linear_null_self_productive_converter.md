# Linear transaction-null germ as a productive nonlinear catalyst

The broad ancestry reservoir need not itself carry the productive `l=2` transaction. The cheapest possible local counterexample is a linear vorticity gradient.

Let

`omega_1=A B x`,

where `B` is symmetric and trace free.

Because the vorticity is linear, its direct Hodge transaction vanishes by angular parity:

`Q[omega_1]=0`.

It is also a viscous zero mode:

`Delta omega_1=0`.

The exact tangent Hodge velocity is

`u_2=-(A/3) x cross Bx`.

It is divergence free, tangent to every centered sphere, and has `curl u_2=omega_1`.

## Exact nonlinear conversion

The Euler vorticity source is

`G_2=(omega_1.grad)u_2-(u_2.grad)omega_1`.

Rotational equivariance says its quadratic STF transaction can only be proportional to `(B^2)_TF`. Direct calculation gives

`Q[G_2](r)=(2/5) A^2 r^2 (B^2)_TF`.

The native Hodge screen of an `r^2` transaction profile is `5/14`, hence

`dS_v/dt=(1/7) A^2 r^2 (B^2)_TF`.

So the leading transaction-null Taylor germ is not dynamically passive. It can continuously generate the leading smooth productive germ through its own Euler nonlinearity.

## Important structural consequence

The null mode itself has no local viscous decay at this order, and the self-interaction begins one homogeneity level higher. Therefore the leading linear coefficient can act as a reusable catalyst in the local Taylor hierarchy while emitting quadratic productive structure.
