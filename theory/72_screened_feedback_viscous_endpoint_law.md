# Screened feedback and the viscous endpoint law

For a radially resummed toroidal Hodge channel

`omega=a(r) x cross grad H_l`,

the angular solid-harmonic carrier is harmonic, so

`Delta omega = D_l a(r) x cross grad H_l`,

where

`D_l a = a'' +(2l+2)a'/r = r^(-2l-2)(r^(2l+2)a')'`.

The lower harmonic feedback moment is

`C_l[a]=-(l+1)/(2l+1) integral_0^L r a(r)[1-(r/L)^(2l+1)] dr`.

The same screen is an adjoint Green coordinate for radial viscosity.  Integration by parts gives

`C_l[D_l a]=(l+1)[a(0)-a(L)]`.

Therefore under pure viscous evolution

`dot C_l = nu(l+1)[a(0)-a(L)]`.

This sharply separates three notions:

1. `C_l[a]=0`: statically lower-silent Hodge shape;
2. `a(0)=a(L)`: first-order viscous preservation of that silence;
3. true viscosity-invariant hidden radial dynamics, which would require the entire endpoint-contrast hierarchy generated by repeated `D_l` to vanish.

The explicit quadratic screened-null profile from module 144 violates condition 2 and is immediately visible to viscosity.  A quartic profile can satisfy conditions 1 and 2 simultaneously, but module 145 shows its second viscous derivative is nonzero.

This does not yet prove that no nontrivial radial profile can remain feedback-silent for all viscous time.  It identifies the exact physical ancestry by which viscosity exposes the hidden radial kernel.
