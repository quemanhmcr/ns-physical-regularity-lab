# Fast zero switching: viscous curvature or degeneracy

Take the trace-free symmetric calibration

`B=g diag(1,-(1-delta),-delta)`.

The weak eigenvalue is `delta g`. If a simple zero is to move relative to the material fluid by one core radius `epsilon` in one time `tau`, the exact zero drift law requires

`|Delta omega_z|=delta g epsilon/(nu tau)`.

Define the physical second-derivative length

`ell_Delta=g/|Delta omega_z|`.

With source Reynolds

`R_s=epsilon^2/(nu tau)`,

we obtain the exact gate

`delta ell_Delta/epsilon=1/R_s`.

At high `R_s`:

- if transversality `delta` stays order one, `ell_Delta/epsilon ->0`: switching requires a sub-core viscous curvature scale;
- if no sub-core curvature is allowed, `delta <=1/R_s`, so `det B/g^3=delta(1-delta)->0`: the zero becomes degenerate.

The degenerate branch remains productive. As `delta->0`,

`(B^2)_TF/g^2 -> diag(1/3,1/3,-2/3)`.

So loss of zero transversality is not self-defeating; it creates a genuine new escape geometry: a line/surface of vorticity zeros can act as a reservoir of transaction-null catalytic ancestry.

The next attack must therefore study the dynamics of degenerate zero manifolds rather than another scalar quantity.
