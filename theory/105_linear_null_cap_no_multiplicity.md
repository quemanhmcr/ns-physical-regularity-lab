# No fixed-time cap multiplicity in the linear null catalyst

The exact recross family shows that one frozen lineage can be counted infinitely many times **over time**. The critical catalyst, however, requires its instantaneous active cap flux to diverge.

For the axisymmetric linear null catalyst

`omega=A(2x,-y,-z)`,

a vortex line satisfies

`x'=2Ax`,

`rho'=-A rho`.

Thus

`C=x rho^2`

is invariant and, in `x>0`, the oriented coordinate `x` is strictly increasing.

Along a line,

`r^2=x^2+C/x`.

Its radial turning point obeys

`2x^3=C`.

The positive outward cap condition is

`omega.n>0`,

which is exactly

`2x^3>C`.

On this branch

`d(r^2)/dx=2x-C/x^2>0`.

Therefore each oriented vortex line intersects the positive cap of a fixed centered sphere at most once.

So the cap circulation in the pure catalyst is an aggregate of distinct through-going flux elements, not repeated fixed-time winding of one element.

This distinction matters:

- cumulative source crossing can be inflated by sequential recrossing of the same ancestry;
- instantaneous cap flux in the near-linear catalyst cannot be inflated by repeated crossings of one line without leaving the monotone catalyst geometry.

The remaining escape is simultaneous folding/multiplicity generated by an additional non-affine actor. A proof must either control that folding or show that producing it re-enters an already taxed ancestry/viscous channel.
