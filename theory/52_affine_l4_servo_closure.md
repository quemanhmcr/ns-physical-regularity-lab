# Affine closure of the dynamically generated `l=4` servo sector

## THINK — one channel failed, but does the whole `l=4` sector stay finite?

The first nonlinear departure from the sharp `l=2` carrier is a pure toroidal `l=4` field `N_4`.  A servo proportional only to `N_4` is not affine-closed: `P_null L_S N_4` has a component orthogonal to `N_4`.

This does **not** yet imply an infinite hierarchy.  The physically correct next question is the dimension of the response space generated by repeatedly applying the actual affine null operator

`K=P_null L_S`.

No modal dimension is chosen beforehand.

## Surface-Hodge test

First resolve both

`K N_4`

and its component orthogonal to `N_4` by radial/tangential and surface-Hodge decomposition.  If all radial and poloidal sectors remain zero and only toroidal `l=4` survives, affine maintenance rotates inside the same angular degree.  Then the first true angular-degree cascade must come from nonlinear interaction with the localized velocity correction, not from the common affine strain.

## Intrinsic Krylov response space

Generate

`N_4, K N_4, K^2 N_4, ...`.

The span is an invariant object.  A monomial coefficient chart may be used only as a numerical rank certificate; it is not the physical representation.

If the certified rank stabilizes, the affine servo burden is finite-dimensional.  This is a favorable outcome for the singular mechanism and should be accepted rather than forced into an infinite hierarchy.

If the rank fills a substantial part of the `l=4` sector, the network must actively control that many independent angular responses just to maintain sharpness under the stationary strain.
