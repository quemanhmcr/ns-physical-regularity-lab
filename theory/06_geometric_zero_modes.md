# Geometric zero modes and the first 3D stretching order parameter

The planar gate suggests that raw displacement amplitude is not the physical variable. Rigid Euclidean motions must be invisible to self-stretching.

For the wavy ring

X(theta) = (R cos theta, R sin theta, eps R sin(m theta)),

m=1 is not genuinely three-dimensional: it is a tilted planar circle. Therefore any physically meaningful small-amplitude stretching coefficient must vanish at m=1.

The first remote data for m=2 and m=3 show that A/eps is numerically close to a common coefficient times (m^2-1). This motivates a falsifiable geometric hypothesis, not an assumption:

A(eps,m,c) = eps (m^2-1) F(m c) + higher order,

where c = core_radius/R and F is a core-filter transfer function. The factor m^2-1 removes the rigid tilt mode; dependence on m c would say that finite core thickness filters geometric waviness according to wavelength/core ratio.

Module 07 attacks this proposed collapse across modes and core sizes. Failure is informative and will kill or refine the proposed order parameter.
